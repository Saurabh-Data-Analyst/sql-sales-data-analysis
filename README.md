# 📊 sql-sales-data-analysis
SQL-based sales data analysis project identifying revenue trends, top products, and customer behavior using advanced queries.

## 📌 Project Overview -

This project focuses on analyzing sales and customer data using SQL Server (SSMS). The goal was to extract meaningful insights related to revenue trends, product performance, and customer purchasing behavior.

## 🎯 Business Objective -

* Analyze sales data to identify revenue trends
* Identify top-performing and low-performing products
* Understand customer purchasing behavior
* Support data-driven decision-making

## 🛠 Tools & Technologies -

* SQL Server (SSMS)
* Data Analysis

## 🧠 SQL Concepts Used -

* SELECT
* WHERE
* GROUP BY
* ORDER BY
* INNER JOIN
* Aggregate Functions (SUM, COUNT, AVG)
* Subqueries
* CASE Statements

## 📊 Key Analysis Performed -

* Top-selling products
* Monthly revenue trends
* Customer purchase behavior
* Product performance analysis

## 📈 Key Insights -

* A small number of products generate the majority of revenue
* Certain months show higher sales trends
* Some products consistently underperform
* Customer buying patterns can be used to improve marketing

## ⚡ Challenges Faced -

* Handling joins across multiple tables
* Dealing with incorrect aggregations
* Removing duplicate data issues

## 🔍 Solution Approach -

* Proper use of primary and foreign keys
* Correct implementation of INNER JOIN
* Accurate use of GROUP BY and aggregations

## 🚀 Performance Optimization -

* Reduced unnecessary columns in SELECT
* Optimized joins
* Improved query performance

## 📁 Dataset -

* Sales dataset containing orders, products, and customer information

## 🎤 Key Business Highlights

### ✔ What was the most challenging part?

Handling joins between multiple tables and fixing incorrect aggregations due to duplicate rows.

### ✔ Why did I use SQL instead of Excel?

SQL is more efficient for handling large datasets and complex operations like joins and aggregations.

### ✔ What SQL concepts did I use?

SELECT, WHERE, GROUP BY, JOINs, aggregate functions, subqueries, and CASE statements.

### ✔ How did this project help the business?

It helped identify top products, sales trends, and customer behavior to improve decision-making.

## 💼 Business Impact

* Identified top-performing products
* Improved understanding of customer behavior
* Enabled better sales and inventory decisions

## 🚀 Conclusion

This project demonstrates how SQL can be used to analyze large datasets efficiently and generate valuable business insights.
